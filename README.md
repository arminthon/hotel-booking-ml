# 🏨 Hotel Booking Cancellation Predictor

پیش‌بینی لغو رزرو هتل با استفاده از یادگیری ماشین و هوش مصنوعی. این پروژه با تحلیل داده‌های واقعی رزرو هتل، احتمال لغو شدن یک رزرو را پیش‌بینی می‌کند تا هتل‌ها بتوانند مدیریت بهتری روی اتاق‌ها و ظرفیت خود داشته باشند.

---

## 🚀 ویژگی‌های اصلی پروژه
- **تحلیل داده‌های بزرگ:** پردازش و پاکسازی دیتاست بزرگ شامل بیش از ۱۱۸,۰۰0 سطر داده‌های واقعی هتل.
- **مهندسی ویژگی (Feature Engineering):** تبدیل متغیرهای متنی به عدد با استفاده از تکنیک One-Hot Encoding و مدیریت ستون‌ها.
- **مدل هوش مصنوعی:** استفاده از الگوریتم قدرتمند **Random Forest Classifier** با دقت بالای **۹۱.۵٪**.
- **وب‌اپلیکیشن تعاملی:** ساخت رابط کاربری زیبا و کاربرپسند با استفاده از کتابخانه **Streamlit**.

---

## 🛠️ تکنولوژی‌ها و کتابخانه‌های استفاده شده
- **Python** (زبان برنامه‌نویسی اصلی)
- **Pandas & NumPy** (پردازش و تحلیل داده)
- **Scikit-Learn** (آموزش مدل هوش مصنوعی و ارزیابی)
- **Joblib** (ذخیره‌سازی و بارگذاری مدل آموزش‌دیده)
- **Streamlit** (پیاده‌سازی وب‌اپلیکیشن)
